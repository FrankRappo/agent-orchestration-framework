# Доставить сообщение ЖИВОМУ агенту (steer running REPL)

Агент framework — интерактивный claude REPL в tmux (сессия `claude_<TASK>_repl`). Можно вклиниться
и дать ему указание/коррекцию/подсказку прямо во время работы: текст вставляется в поле ввода REPL и
уходит как следующий пользовательский ход (агент подхватит между ходами). Это преимущество интерактивного
режима над `claude -p`.

## Как (от пользователя агента, agentuser; кириллица/многострочное — через paste-buffer, не type)
```bash
S=claude_<TASK>_repl                            # ТОЧНОЕ имя REPL-сессии, БЕЗ префикса '='
cat > /tmp/msg.txt <<'EOF'
<текст указания агенту — ёмко, по делу>
EOF
runuser -u agentuser -- tmux load-buffer  -b amsg /tmp/msg.txt
runuser -u agentuser -- tmux paste-buffer -b amsg -t "$S"
sleep 1
runuser -u agentuser -- tmux send-keys        -t "$S" Enter
```

## Грабли
- 🔴 Для `paste-buffer`/`send-keys` цель `-t` — ПРОСТОЕ имя сессии, БЕЗ `=`. Префикс `=` (exact-match)
  годится только для `has-session`/`kill-session`; с `paste-buffer`/`send-keys` он даёт «can't find pane».
- Проверить, что сессия жива (тут `=` уместен): `runuser -u agentuser -- tmux has-session -t "=$S"`.
- Сообщение уходит как обычный user-turn — агент увидит его СЛЕДУЮЩИМ ходом (если сейчас занят, встанет
  в очередь). jsonl может «не расти» сразу после вставки — это норма (агент между ходами), подхватит.
- 🔴 Очередь подхватывается только МЕЖДУ ходами. Если агент прямо СЕЙЧАС делает вредное (правит/пересобирает/
  деплоит) и ждать конца хода нельзя — после вставки сообщения послать `Escape`, чтобы ПРЕРВАТЬ текущий ход
  немедленно; тогда стоп-руль станет активной инструкцией сразу (кейс PROJECTA T60, GOTCHAS #8):
  `runuser -u agentuser -- tmux send-keys -t "$S" Escape`. Прерывание безопасно, если у таска есть backup-before-edit
  (правку откатят из pre-edit снапшота).
- Не спамить: одно ёмкое сообщение за раз. Длинную инструкцию/процедуру лучше положить в файл и дать
  агенту ПУТЬ на Read, а не копипастить целиком.
- Заглянуть глазами в живой REPL: `runuser -u agentuser -- tmux attach -t "$S"` (Ctrl-b d — отцепиться).

## Когда полезно
- Коррекция диагноза на лету (пример: «AnyDesk не завис — сделай Retry + введи пароль»).
- Скормить проверенную процедуру/док (дать путь на Read вместо изобретания).
- Сузить/расширить рамки, снять ложный блокер, попросить промежуточный STATUS.
