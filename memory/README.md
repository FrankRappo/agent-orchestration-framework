# Память оркестратора во фреймворке

Зеркало каталога `/root/.claude/projects/-root/memory/` (перенесено T200, 07.08.2026).

* **Источник истины — оригинал в `/root/.claude/...`**: его читает и пишет живая сессия
  оркестратора. Оригиналы НЕ удалены и удаляться не должны.
* Эта копия существует, чтобы память жила внутри фреймворка, попадала в git и была видна
  следующему агенту, который придёт читать `/work/settings`.
* Индекс памяти — `MEMORY.md` (перенесён как есть, вместе с frontmatter каждого файла).
* Общая карта фреймворка — [`../docs/FRAMEWORK_LAYOUT.md`](../docs/FRAMEWORK_LAYOUT.md).

🔴 Синхронизация ручная. Если правишь память оркестратора — правь оригинал в `/root/...`,
а сюда копируй:

```bash
sudo bash -c 'cp -p /root/.claude/projects/-root/memory/*.md /work/settings/memory/ \
  && chown agentuser:agentuser /work/settings/memory/*.md'
```
